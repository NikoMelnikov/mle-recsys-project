# Подготовка виртуальной машины

## Склонируйте репозиторий

Склонируйте репозиторий проекта:

```
git clone https://github.com/yandex-praktikum/mle-project-sprint-4-v001.git
```

## Активируйте виртуальное окружение

Используйте то же самое виртуальное окружение, что и созданное для работы с уроками. Если его не существует, то его следует создать.

Создать новое виртуальное окружение можно командой:

```
python3 -m venv env_recsys_start
```

После его инициализации следующей командой

```
. env_recsys_start/bin/activate
```

установите в него необходимые Python-пакеты следующей командой

```
pip install -r requirements.txt
```

### Скачайте файлы с данными

Для начала работы понадобится три файла с данными:
- [tracks.parquet](https://storage.yandexcloud.net/mle-data/ym/tracks.parquet)
- [catalog_names.parquet](https://storage.yandexcloud.net/mle-data/ym/catalog_names.parquet)
- [interactions.parquet](https://storage.yandexcloud.net/mle-data/ym/interactions.parquet)
 
Скачайте их в директорию локального репозитория. Для удобства вы можете воспользоваться командой wget:

```
wget https://storage.yandexcloud.net/mle-data/ym/tracks.parquet

wget https://storage.yandexcloud.net/mle-data/ym/catalog_names.parquet

wget https://storage.yandexcloud.net/mle-data/ym/interactions.parquet
```

Код для выполнения первой части проекта находится в файле `recommendations.ipynb`. Изначально, это шаблон. Используйте его для выполнения первой части проекта.

# Сервис рекомендаций

Код сервиса рекомендаций находится в файле `recommendations_service.py`.

Основные настройки Сервиса рекомендаций находятся в файле .env_service, это url для доступов к сервисам и пути к заранее расчитанным рекомендациям.
    Непосредственно сервис готовился на основе теоретического материала и особого волюнтаризма не содержит.
Сервис рекомендаций состоит из непосредственно recommendation_service возвращающего набор рекомендаций,
events_service который сохраняет взаимодействие пользователя с треками и features_service который на основе полученных из events_service взаимодействий формирует онлайн рекомендации для пользователя по принципу похожести объектов (item2item similarity).
    recommendation_service возвращает рекомендации по принципу:
    1. Холодный пользователь который не взаимодействовал еще с треками получит предложение прослушать топ популярные треки.
    2. Пользователь который имеет историю взаимодействий получит рассчитанные персональные рекомендации и топ популярных.
    3. Пользователь который имеет историю взаимодействий и рассчитанные онлайн рекомендации (взаимодействует в моменте с треками) получит топ популярные треки и рекомендации построенные по схеме блендинга. А именно:
    - онлайн-рекомендации занимают нечётные места,
    - офлайн-рекомендации занимают чётные места.
    4. Холодный пользователь который в моменте взаимодействует с треками, получит получит топ популярные треки и расчитанные онлайн рекомендации.

Для запуска Сервиса рекомендаций необходимо последовательно в терминале выполнить три bash скрипта:
uvicorn recommendation_service:app
uvicorn features_service:app --port 8010
uvicorn events_service:app --port 8020

# Инструкции для тестирования сервиса

Код для тестирования сервиса находится в файле `test_service.py`. Данный сервис в своюочередь обращается к файлу 'app.py' котрый содержит функцию get_recommendations() для возможности ее отладки и подстройки при необходимости.
Сервис `test_service.py` в сути довольно прост и работает по принципу:
1. Формирует предложенные события для предложенных пользователей.
2. Получает рекомендации трех типов для предложенных пользователей.
Пользователей и события возможно настраивать в файлах params.json и events.json соответсвенно, без вмешательства в код сервиса тестирования.
Запустить сервим тестирования возможно скриптом:

python -m unittest test_service.py
